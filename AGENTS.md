# AI Chief Secretary — Norrapat

This repository is the product workbench for AI Chief Secretary.

Read these before acting:

1. `agent_state.json` — the last verified state.
2. `task_board.json` — active work, owner, deadline, cost, expected value, and next action.
3. `docs/agent-rules.md` — operating and approval rules.
4. `docs/reliability-policy.md` — safeguards.
5. `docs/handoff-protocol.md` — required session handoff.
6. `docs/reviewer-rubric.md` — acceptance standard.
7. `docs/references/ai-engineering-from-scratch.md` — reference capability map.

Every task must include SIPOC, owner, deadline, cost, expected value, acceptance criteria, evidence, and next action.
Never claim completion without stored evidence and a completed verification record.
